# Production conversation hierarchy

Operate mode. Preserve Pi Remote typography, themes, navigation, and the production composer.

Independent conversations belong in the global list. Coordinator workers are children, not peer conversations. Keep their names and states visible below the coordinator header, with direct entry and an explicit return to the owner. Working children remain reachable without Session details. Full assignments and reports use the existing Background tasks inspector.

Conversation and composer remain the primary task area. Keep the worker group bounded on short viewports, preserve keyboard focus during status updates, and distinguish waiting questions, returned reports, accepted results, and interrupted work with text.

This is production behavior, not the isolated coordinator prototype or approval of its rejected visual studies.
